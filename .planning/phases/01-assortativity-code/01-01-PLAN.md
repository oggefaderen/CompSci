Cell 2 — code (Q1 country assortativity using Newman eq. 2 mixing matrix):
```python
# Q1: Country assortativity using Newman equation 2 (mixing matrix approach)
# e_ij = fraction of edges connecting country i to country j
# r = (Tr(e) - ||e^2||) / (1 - ||e^2||)

# Build mixing matrix counts — skip edges where either node has no country
edge_counts = defaultdict(int)
total_edges = 0

for u, v in G.edges():
    c_u = G.nodes[u].get('country')
    c_v = G.nodes[v].get('country')
    if c_u is None or c_v is None:
        continue
    edge_counts[(c_u, c_v)] += 1
    if c_u != c_v:
        edge_counts[(c_v, c_u)] += 1  # symmetric: undirected graph
    total_edges += 1

# e_ij: fraction of edges (symmetric, total_edges counted once per undirected edge)
countries = sorted(set(c for (c, _) in edge_counts))
e = {}
for c_i in countries:
    for c_j in countries:
        e[(c_i, c_j)] = edge_counts.get((c_i, c_j), 0) / (2 * total_edges)

# Tr(e): sum of diagonal (same-country edges)
trace_e = sum(e[(c, c)] for c in countries)

# a_i = sum_j e_ij (row sums = marginal distribution)
a = {c: sum(e[(c, c2)] for c2 in countries) for c in countries}

# ||e^2|| = sum_i a_i^2
sum_a_sq = sum(a[c]**2 for c in countries)

# Newman equation 2
original_country_r = (trace_e - sum_a_sq) / (1 - sum_a_sq)

print(f"Country assortativity r = {original_country_r:.4f}")
```

Key correctness notes for the executor:
- Each undirected edge (u,v) contributes 1 to total_edges
- For the symmetric mixing matrix, (u,v) with countries (i,j) increments both e[i,j] and e[j,i], so both off-diagonal and diagonal are counted correctly
- The diagonal e[i,i] is edges where both endpoints have country i — these are counted once in total_edges but contribute to BOTH e[i,j] and e[j,i] entries when i==j (same entry, so actually: for diagonal, only increment once)

CORRECTED approach — simpler and unambiguous:
```python
# Q1: Country assortativity using Newman equation 2 (mixing matrix approach)
edge_type_counts = defaultdict(int)
total_edges = 0

for u, v in G.edges():
    c_u = G.nodes[u].get('country')
    c_v = G.nodes[v].get('country')
    if c_u is None or c_v is None:
        continue
    # Treat as undirected: always store both orderings
    edge_type_counts[(c_u, c_v)] += 1
    if c_u != c_v:
        edge_type_counts[(c_v, c_u)] += 1
    total_edges += 1

countries = sorted(set(c for (c, _) in edge_type_counts))
M = 2 * total_edges  # denominator: counts each edge in both directions

# e_ij fraction
e = {(c_i, c_j): edge_type_counts.get((c_i, c_j), 0) / M for c_i in countries for c_j in countries}

# Trace and marginal sums
trace_e = sum(e[(c, c)] for c in countries)
a = {c: sum(e[(c, c2)] for c2 in countries) for c in countries}
sum_a_sq = sum(a[c]**2 for c in countries)

original_country_r = (trace_e - sum_a_sq) / (1 - sum_a_sq)
print(f"Country assortativity r = {original_country_r:.4f}")
```
